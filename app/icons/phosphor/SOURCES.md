# Phosphor icon sources

All SVGs in this directory are the **Regular** weight source assets from the
official [Phosphor Icons core repository](https://github.com/phosphor-icons/core),
retrieved 2026-09-17.

- Asset path: `https://raw.githubusercontent.com/phosphor-icons/core/main/assets/regular/<icon>.svg`
- Source repository and asset structure: <https://github.com/phosphor-icons/core>
- License: [MIT License](https://github.com/phosphor-icons/core/blob/main/LICENSE)

The bundled `LICENSE` is the unmodified upstream license. Phosphor's regular
SVGs use `viewBox="0 0 256 256"` and `fill="currentColor"`; size them through
CSS (`width` and `height`) and inherit their color from the parent. They are
filled paths that render as Phosphor's regular, rounded-outline visual weight,
so do not add a CSS stroke to the SVG.
