From a five-minute task
to a proposed deliverable.

The order is the operation design. Every step needs an owner, a pass criterion and a recovery path before field collection starts.

    Recruit

    Participant channels and device-fit checks are defined during program scoping.

    BASE60

    Guide & consent

    BASE60

  4. 04

06 / Deliverable

What can be specified in a buyer package.

Video
MP4, landscape 1080p30, head-mounted ultra-wide. Stereo option on commercial track.
Format
Proposed formats include raw MP4, per-task JSON and dataset cards. Training-framework conversion can be scoped per buyer.
Metadata
Task id, environment, device, start/end photos, timestamps, review verdict and reason codes.
Labels
Temporal segments, optional 3D hand pose, object 6-DoF, KR/EN natural-language description.
Documents
Dataset card, QA report and privacy report templates can be prepared per batch.
Acceptance
Segment-level invalidation is proposed by default. Reshoot policy is set during scoping.
07 / Rights & privacy

The first thing foreign buyers ask. Designed up front.

Contracts
Draft agreement set in Korean and English: IP terms, personal-data consent (PIPA), likeness release and facility permission.
De-identification
Automated flagging and blur can be paired with human verification when collection moves beyond prototype.
Exclusions
Participant faces, minors, medical documents and financial documents can be defined as excluded content.
License tiers
Exclusive custom · Hybrid custom (reduced fee, we keep resale) · Non-exclusive library.
Jurisdiction
Korean entity and cross-border buyer terms to be confirmed in final contracts.
